# Event Planner (backend)

Generates printable materials needed for an annual group trip. Event coordinator enters a list of attendees, assigns seating graphically, then executes CTA to render place cards, table tents, and seating chart. Built using Sass, React, Router, TanStack Query, TypeScript, Node.js, Express, MongoDB, and PdfLib.

[corresponding frontend repository](https://github.com/scosut/event-planner-frontend)
